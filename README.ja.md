# 英雄叙記2 リマスター

[한국어](README.md) · [English](README.en.md) · 日本語

携帯電話向けゲーム『英雄叙記2 氷海の剣士』（原題：영웅서기2: 빙해의 검사）を、WindowsとAndroid向けにUnityで作り直した非公式の個人制作プロジェクトです。ナイト・バーサーカー・ローグから職業を選び、野獣を育てて共に戦いながら、クレールの物語を進めていきます。

原作の物語や戦闘・成長システムをもとに、各プラットフォームに合わせた操作と画面表示を採用し、進行状況は端末に保存されます。無料で配布し、韓国語・英語・日本語に対応しています。

メインストーリーやサブクエストを進めながらスキルを習得し、装備の強化・属性付与・アイテム合成や野獣の進化を利用できます。ノーマルの後には、ハードコア・ヘルの周回が続きます。

## ダウンロードと起動

### Windows（64ビット）

1. [Releases](https://github.com/Donamet/Heroes-Lore-2-Remastered-Public/releases)からWindows用のゲームZIPをダウンロードします。GitHubが自動で生成する`Source code`は、ゲームの実行用ファイルではありません。
2. ZIP全体を任意のフォルダーに展開します。
3. `Heroes Lore 2 Remastered.exe`を起動します。データフォルダーやDLLも、EXEと同じ場所に置いてください。

配布対象は64ビット版Windows PCです。Unity EditorやSteamのインストールは不要で、インターネットに接続せずにプレイできます。

### Android（8.0以降）

[v1.0.2のリリースページ](https://github.com/Donamet/Heroes-Lore-2-Remastered-Public/releases/tag/v1.0.2)からスマートフォンやタブレットにAPKをダウンロードし、開いてインストールします。Androidの確認画面が表示された場合は、APKを開いたアプリからのインストールを許可してください。ゲームは横画面でプレイできます。

## 操作方法

WindowsではXboxとPlayStationのコントローラーに対応しています。コントローラーでオプションの操作設定を開くと、ボタンの割り当てを変更・保存できます。Androidのタッチボタンは大きさを調整でき、コントローラーを接続すると非表示になります。

初期状態のキー割り当ては以下のとおりです。設定画面で変更できます。

| 操作 | 初期キー |
| --- | --- |
| 移動・メニュー選択 | 方向キー |
| 通常攻撃・会話・調べる・決定 | Space |
| 職業スキル 1 / 2 / 3 / 4 | Z / X / C / V |
| 選択中の消費アイテムを使う | A |
| 消費アイテムの切り替え | 左Shift |
| ミニマップ | M |
| メニューを開く・キャンセル・戻る | Esc |
| 会話・カットシーンのスキップ | 左Shift |
| ステータス / 持ち物 / スキル / クエスト / 野獣 | P / I / K / Q / T |

EnterとテンキーのEnterでも決定できます。キーを変更すると、ゲーム内の操作ガイドにも反映されます。

## Windowsの言語と画面の設定

初回起動時は、Windowsの言語が韓国語なら韓国語、日本語なら日本語、それ以外なら英語で始まります。ゲーム内で言語を選んだ後はその設定を保存し、Windowsの言語よりも優先します。

設定画面では、言語、音量、BGM・効果音、ゲーム速度、カメラの動作、解像度、画面モード、キー割り当てを変更できます。解像度は1280×720、1366×768、1920×1080、2560×1440から選べます。ウィンドウとボーダーレス全画面に対応しています。

原作の韓国語テキストを英語・日本語に翻訳しています。もともと英語が描かれていたUI画像はそのまま使用しているため、日本語でプレイしても一部の見出しや表記は英語のままです。

## 原作からの変更点

| 項目 | リマスターでの動作 |
| --- | --- |
| マップとカメラ | 小さなマップをつなぎ、広いエリアとして構成しています。つながったエリア内はそのまま移動できますが、出入口や別エリアへの切り替えは残っています。カメラは統合したマップの外周に沿って動きます。 |
| 操作とメニュー | キー変更、メニューへのショートカット、現在のキーを表示する操作ガイドを追加しています。装備の着脱には確認画面があり、装備一覧は装備できるものを先に表示します。 |
| ゲーム速度 | 初期速度を原作のFASTからFASTERに変更しています。設定で速度を選ぶと、移動やアニメーションの速度も変わります。 |
| 文字と画面 | PCの解像度に合わせてUIを配置し、翻訳文にドットフォントを使用しています。長い名前は横にスクロールし、スキル名は選択中だけスクロールします。エンディングの会話も通常の会話と同じウィンドウ・文字表示を使用します。 |
| 音楽と効果音 | BGMと効果音を別々に再生します。効果音によってBGMが途切れたり、最初から再生されたりすることはありません。 |
| セーブと設定 | PC内の別々のフォルダーに保存します。セーブが破損していて有効なバックアップがある場合は、復旧を試みます。 |
| ネットワーク機能 | シングルプレイ専用です。原作のネットワーク対戦は含まれません。関連するヘルプと原作の開発会社案内の章も削除しています。 |

## Windowsのセーブとアップデート

セーブと設定は、インストール先とは別の場所に保存されます。エクスプローラーのアドレスバーに次のパスを貼り付けると開けます。

```text
%USERPROFILE%\AppData\LocalLow\Donamet_dev\Heroes Lore 2 Remastered
```

`Saves`にはゲームの進行、`Settings`には言語・キー・画面などの設定が入っています。アップデートや別のPCへの移行前には、ゲームを終了し、このフォルダー全体をコピーして保管してください。

アップデート時は、新しいバージョンのZIPを新しいフォルダーに展開して起動します。上記の保存先を削除しなければ、進行と設定を引き継げます。

進行の保存には、ゲーム内のセーブ機能を使ってください。データのあるスロットで新しいゲームを始めた場合、その後セーブすると以前の進行を上書きします。

## 対応範囲と不具合報告

Windows版とAndroid版を配布しています。Steam連携、クラウドセーブ、実績も含まれません。翻訳やUIの不自然な箇所、進行できなくなる不具合は[Issues](https://github.com/Donamet/Heroes-Lore-2-Remastered-Public/issues)へお寄せください。

報告には、ゲームのバージョン、言語、職業、発生場所、再現手順を記載してください。スクリーンショットや問題が起きる前のセーブがあると確認に役立ちます。ファイルを添付する際は、PCのユーザー名など、公開したくない情報が含まれていないか確認してください。
