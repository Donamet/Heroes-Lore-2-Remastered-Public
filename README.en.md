# Heroes Lore 2 Remastered

[한국어](README.md) · English · [日本語](README.ja.md)

An unofficial personal project that rebuilds the Korean mobile RPG Heroes Lore 2 (영웅서기2: 빙해의 검사) in Unity for Windows and Android. Follow Claire's story as a Knight, Berserker, or Rogue, and fight alongside a Beast companion.

The game retains the original story and uses its combat and progression systems with controls and layouts tailored to each platform and local saves. It is free to download and supports Korean, English, and Japanese.

Progress through the main story and side quests, learn skills, enhance and imbue equipment, craft items, and evolve your Beast. Hardcore and Hell playthroughs follow Normal mode.

## Download and play

### Windows (64-bit)

1. Download the Windows game ZIP from [Releases](https://github.com/Donamet/Heroes-Lore-2-Remastered-Public/releases). The `Source code` archives generated by GitHub are not playable builds.
2. Extract the entire ZIP to a folder of your choice.
3. Run `Heroes Lore 2 Remastered.exe`. Keep the data folder and DLL files alongside the EXE.

The build is for 64-bit Windows PCs. You do not need Unity Editor or Steam to play. The game works offline.

### Android (8.0 or later)

Download the APK from the [v1.0.2 release](https://github.com/Donamet/Heroes-Lore-2-Remastered-Public/releases/tag/v1.0.2) to your phone or tablet, then open it to install. If prompted, allow the app you opened the APK with to install apps. Launch the game in landscape.

## Controls

Windows supports Xbox and PlayStation controllers. Open **Options → Controls** with a controller to remap and save its buttons. Android has resizable touch controls that hide when a controller is connected.

These are the default keyboard controls. You can change them in the controls settings.

| Action | Default key |
| --- | --- |
| Move or navigate menus | Arrow keys |
| Basic attack, talk, interact, or confirm | Space |
| Class skills 1 / 2 / 3 / 4 | Z / X / C / V |
| Use the selected consumable | A |
| Cycle consumables | Left Shift |
| Minimap | M |
| Open menu, cancel, or go back | Esc |
| Skip dialogue or cutscenes | Left Shift |
| Status / Inventory / Skills / Quests / Beast | P / I / K / Q / T |

Enter and Numpad Enter also confirm. In-game control hints update when you change a binding.

## Windows language and display settings

On first launch, the game selects Korean or Japanese if Windows uses that language. For other Windows languages, it starts in English. Once you choose a language in the game, that saved choice takes priority over the Windows language.

The settings cover language, volume, BGM, sound effects, game speed, camera behavior, resolution, display mode, and key bindings. Available resolutions are 1280×720, 1366×768, 1920×1080, and 2560×1440. Windowed and borderless fullscreen modes are supported.

Text originally written in Korean has been translated into English and Japanese. UI artwork that already contained English lettering is preserved, so some headings and labels remain in English when playing in Japanese.

## Differences from the original

| Area | Behavior in the remaster |
| --- | --- |
| Maps and camera | Small maps have been joined into larger areas. You can move continuously within connected areas; entrances and transitions to separate areas remain. The camera follows the outer boundary of the combined map. |
| Controls and menus | Keyboard bindings, menu shortcuts, and hints for the current keys have been added. Equipping and unequipping ask for confirmation, and equipment lists show items you can equip first. |
| Game speed | The default changes from the original FAST setting to FASTER. You can select another speed in settings; movement and animation rates change with it. |
| Text and layout | UI layouts fit PC resolutions, with pixel fonts for translated text. Long names scroll horizontally; skill names scroll only while selected. Ending dialogue uses the same window and text rendering as regular dialogue. |
| Music and sound | BGM and sound effects play separately. A sound effect does not interrupt or restart the background music. |
| Saves and settings | Both are stored locally on the PC, in separate folders. If a save is damaged and a valid backup exists, the game attempts to recover it. |
| Network features | The game is single-player only. The original network battles are not included. Their help text and the original developer information chapter have also been removed. |

## Saves and updates on Windows

Saves and settings are separate from the installation folder. Paste this path into the File Explorer address bar to open it:

```text
%USERPROFILE%\AppData\LocalLow\Donamet_dev\Heroes Lore 2 Remastered
```

`Saves` contains game progress. `Settings` contains preferences such as language, controls, and display settings. Before updating or moving to another PC, close the game and copy this entire folder somewhere safe.

To update, extract the new version into a new folder and run it. Keep the data at the path above to retain your progress and preferences.

Use the in-game save function to save your progress. If you start a new game in an occupied slot, saving that new game will overwrite the slot's previous progress.

## Support and bug reports

Builds are available for Windows and Android. Steam integration, cloud saves, and achievements are not included. Report translation issues, UI problems, or progression blockers through [Issues](https://github.com/Donamet/Heroes-Lore-2-Remastered-Public/issues).

Include the game version, language, class, location, and steps to reproduce the problem. A screenshot or a save from before the problem can help. Before attaching files, check for information you do not want to share publicly, such as your PC username.
