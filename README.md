# 영웅서기2 리마스터

한국어 · [English](README.en.md) · [日本語](README.ja.md)

휴대전화 게임 『영웅서기2: 빙해의 검사』를 Windows와 Android에서 플레이할 수 있도록 Unity로 다시 만든 비공식 개인 프로젝트입니다. 클레르의 이야기를 따라가며 나이트·버서커·로그 중 하나의 직업을 선택하고, 야수와 함께 싸우고 성장할 수 있습니다.

원작의 이야기와 전투·성장 시스템을 바탕으로 플랫폼에 맞는 조작과 화면을 적용했으며, 진행 상황은 기기에 저장합니다. 한국어·영어·일본어를 지원하며, 무료로 배포합니다.

메인 스토리와 서브 퀘스트를 진행하며 스킬을 익히고, 장비 강화·속성 부여·조합과 야수 진화를 이용할 수 있습니다. 노멀 이후에는 하드코어·헬 회차가 이어집니다.

## 1.0.2 업데이트

[저장 / 이어하기]
- 윈터하츠의 다른 구역, 실내 또는 연결부에서 저장한 뒤 이어하기를 하면 볼프강 부하의 초반 대화가 진행되지 않던 오류를 수정했습니다.

[NPC 표시]
- NPC 머리 위 !와 ?의 움직임 속도를 NPC 본체 애니메이션 속도와 동기화했습니다.

[Android]
- 일반 대화 중 기존 메뉴/취소 버튼 위치에 스킵 버튼을 추가했습니다.
- 스킬 쿨다운 표시 방식을 변경하였습니다.


## 다운로드와 실행

### Windows (64비트)

1. [Releases](https://github.com/Donamet/Heroes-Lore-2-Remastered-Public/releases)에서 Windows용 게임 ZIP을 받습니다. GitHub가 자동으로 제공하는 `Source code` 파일은 실행용 게임이 아닙니다.
2. ZIP 전체를 원하는 폴더에 압축 해제합니다.
3. `Heroes Lore 2 Remastered.exe`를 실행합니다. EXE 옆의 데이터 폴더와 DLL도 함께 있어야 합니다.

배포 대상은 Windows 64비트 PC입니다. 게임을 실행하기 위해 Unity Editor나 Steam을 설치할 필요는 없습니다. 인터넷 연결 없이 플레이할 수 있습니다.

### Android (8.0 이상)

[v1.0.2 릴리스](https://github.com/Donamet/Heroes-Lore-2-Remastered-Public/releases/tag/v1.0.2)에서 APK를 휴대폰이나 태블릿에 내려받아 설치합니다. Android에서 요청하면 APK를 연 앱에 설치 권한을 허용합니다. 게임은 가로 화면으로 플레이합니다.

## 조작

Windows는 Xbox와 PlayStation 컨트롤러를 지원합니다. 컨트롤러로 **옵션 → 조작**을 열면 버튼을 재지정하고 저장할 수 있습니다. Android는 크기를 조절할 수 있는 터치 버튼을 지원하며, 컨트롤러를 연결하면 터치 버튼이 숨겨집니다.

기본 키는 다음과 같습니다. 환경설정의 키 설정에서 변경할 수 있습니다.

| 동작 | 기본 키 |
| --- | --- |
| 이동·메뉴 선택 | 방향키 |
| 기본 공격·대화·상호작용·확인 | Space |
| 직업 스킬 1 / 2 / 3 / 4 | Z / X / C / V |
| 선택한 소비 아이템 사용 | A |
| 소비 아이템 전환 | 왼쪽 Shift |
| 미니맵 | M |
| 메뉴 열기·취소·뒤로가기 | Esc |
| 대화·컷신 스킵 | 왼쪽 Shift |
| 상태 / 가방 / 스킬 / 퀘스트 / 야수 | P / I / K / Q / T |

Enter와 숫자패드 Enter도 확인에 사용할 수 있습니다. 실제 키를 변경하면 게임 내 조작 안내에도 반영됩니다.

## Windows 언어와 화면 설정

처음 실행하면 Windows 언어가 한국어일 때는 한국어, 일본어일 때는 일본어를 선택합니다. 그 밖의 언어는 영어로 시작합니다. 이후에는 환경설정에서 선택한 언어를 기억하므로 Windows 언어를 바꿔도 게임의 저장된 언어 설정을 우선합니다.

환경설정에서 언어, 음량, BGM·효과음, 게임 속도, 카메라 동작, 해상도, 화면 모드와 키 설정을 바꿀 수 있습니다. 해상도는 1280×720, 1366×768, 1920×1080, 2560×1440이며 창 모드와 테두리 없는 전체 화면을 지원합니다.

한국어로 된 문구를 영어·일본어로 번역했습니다. 원래 영문으로 그려져 있던 UI 이미지는 유지하므로 일본어를 선택해도 일부 메뉴 제목과 표기는 영어로 나옵니다.

## 원작과 달라진 점

| 항목 | 리마스터에서의 동작 |
| --- | --- |
| 맵과 카메라 | 여러 작은 맵을 연결해 넓은 구역으로 구성했습니다. 연결된 구역 안에서는 이어서 이동하며, 출입구와 별도 구역의 전환은 남아 있습니다. 카메라는 연결된 맵의 외곽을 기준으로 움직입니다. |
| 조작과 메뉴 | 키보드 조작과 키 변경, 메뉴 바로가기, 현재 키 안내를 추가했습니다. 장비 장착·해제에는 확인창이 있고, 장비 목록은 착용 가능한 항목을 먼저 보여 줍니다. |
| 게임 속도 | 기본 속도를 원작의 FAST에서 FASTER로 바꿨습니다. 환경설정에서 속도를 바꿀 수 있으며, 선택한 속도에 맞춰 이동과 애니메이션 속도가 함께 바뀝니다. |
| 글자와 화면 | PC 해상도에 맞춰 UI를 배치하고 다국어 도트 글꼴을 적용했습니다. 긴 이름은 가로로 흐르며, 스킬 이름은 선택했을 때만 흐릅니다. 엔딩 대화도 일반 대화와 같은 창과 글자 표시 방식을 사용합니다. |
| 음악과 효과음 | BGM과 효과음을 별도로 재생합니다. 효과음 때문에 배경음악이 끊기거나 처음부터 다시 재생되지 않습니다. |
| 저장과 설정 | PC의 로컬 파일에 저장합니다. 게임 진행과 환경설정은 별도로 관리하며, 유효한 백업이 있으면 손상된 저장의 복구를 시도합니다. |
| 네트워크 기능 | 싱글 플레이만 제공합니다. 원작의 네트워크 대전은 포함하지 않으며, 관련 도움말과 개발업체 안내 장도 제외했습니다. |

## Windows 저장과 업데이트

저장과 설정은 게임 설치 폴더와 분리된 다음 경로에 있습니다. 탐색기 주소창에 그대로 붙여 넣어 열 수 있습니다.

```text
%USERPROFILE%\AppData\LocalLow\Donamet_dev\Heroes Lore 2 Remastered
```

`Saves`에는 게임 진행, `Settings`에는 언어·키·화면 등의 설정이 들어 있습니다. 업데이트하거나 다른 PC로 옮기기 전에는 게임을 종료하고 이 폴더 전체를 복사해 보관하세요.

업데이트할 때는 새 버전 ZIP을 새 폴더에 압축 해제해 실행하면 됩니다. 위 저장 경로를 지우지 않으면 진행과 설정을 유지할 수 있습니다.

저장은 게임 내 저장 기능을 이용하세요. 기존 데이터가 있는 슬롯에서 새 게임을 시작한 뒤 저장하면 해당 슬롯의 이전 진행을 덮어씁니다.

## 지원 범위와 제보

Windows와 Android용 빌드를 제공합니다. Steam 연동, 클라우드 저장과 도전과제도 포함하지 않습니다. 번역이나 UI에서 어색한 부분, 진행을 막는 문제를 발견하면 [Issues](https://github.com/Donamet/Heroes-Lore-2-Remastered-Public/issues)에 남겨 주세요.

제보에는 게임 버전, 언어, 직업, 발생 장소와 재현 순서를 적어 주세요. 스크린샷이나 문제가 발생하기 전의 저장이 있으면 확인에 도움이 됩니다. 파일을 첨부할 때는 PC 사용자 이름 등 공개하고 싶지 않은 정보가 포함되어 있는지 확인해 주세요.
